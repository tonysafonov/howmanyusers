# Changelog

## 0.1.0 (2026-11-08)

First release as its own repo and Claude Code plugin (previously `perf-lab` in tony-skills).

- The procedure: frame the question, pre-scan the code, rent and check a two-box rig, calibrate against a published
  reference, model real users, a stand that mirrors production, staircase then 5-minute holds, CPU prices and
  profiles at saturation, a fix ladder, a chaos test, an honest report and a production handoff.
- Pre-scan (`references/prescan.md`) with a real example on gramkit.
- Profiling for Python (py-spy) and Node/Bun (`--cpu-prof`, `perf`).
- Scripts: preflight, staircase and holds, CPU price per endpoint, py-spy + stack classifier, chaos, A/B by commit,
  memory burst and stream probes, a Postgres major-upgrade rehearsal with a fingerprint diff, an LLM stub, signed
  Telegram Mini App test users.
